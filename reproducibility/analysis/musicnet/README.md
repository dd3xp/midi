# Frozen MusicNet metric reproduction

Run `python reproduce_musicnet.py` in this directory with NumPy and SciPy. No GPU, raw recordings or checkpoint is required to reproduce metrics. Inputs contain the retained 20 features, complete RMS targets and original aligned note arrays for all 21 recordings / five works. Predictions include all seven fixed predictors. The script verifies hashes, reconstructs training-fitted references, recomputes all metrics and fixed-output scales, and checks every paired work effect, equal-recording/equal-work mean and 5,000-draw work bootstrap. It reproduces the frozen model choice from all saved original-validation metrics. It writes `recomputed_verification.json` separately from frozen results.

The source directory preserves original in-workspace extraction/inference programs; their paths document that execution and are not a second turnkey training pipeline. To rerun neural inference, use the separately supplied execution companion's fold-0 seed-42 checkpoints and source, together with the frozen configuration, hashes and runtime amendments. No retraining or new model selection is involved. The original WAV/CSV release and license are linked in the plan and acquisition provenance; raw recordings are not redistributed. New derived arrays retain the source data's applicable license and attribution. This local bundle has not been publicly released.

The new protocol was frozen before MusicNet outputs. It does not erase the original 186-track development history. Overlapping note intervals refer to the solo recording, not separated single-note energy. Five works cannot establish broad population generalization. Failed pre-inference checks and the documented runtime amendment remain visible. Both successful GPU inference jobs are complete; speed comparisons across their different devices are not made.
