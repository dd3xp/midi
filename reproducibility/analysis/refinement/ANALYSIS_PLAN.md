# Frozen-output refinement plan

Written before these additional calculations, after the v0.24 review. This is a prospective specification for a retrospective sensitivity analysis, not preregistration or independent validation.

Inputs: the existing companion analysis_arrays.npz, tracks.json, expected_results.json and level_and_aggregation_audit.json. Record SHA-256 and UTC at execution; never alter predictions, targets, splits or models.

1. For Mamba minus instrument OLS and shared envelope, retain all 186 tracks and compute Full and Note correlation differences and log note-RMSE reduction (positive means improvement). Count all four direction quadrants, exact ties separately. Report conditional group-bootstrap intervals for the proportion of tracks with Full improvement but Note deterioration, and among Full-improved tracks, with 5,000 whole-group resamples, seed 20260911. These signs are descriptive, not per-track significance tests.
2. Plot all tracks without filtering. For each comparison, choose one case from Full-positive/Note-negative and one Full-positive/Note-positive quadrant, nearest the quadrant's coordinate-wise median after scaling each coordinate by its IQR (fallback 1 when zero); break ties lexicographically by track. Display a fixed ten-second window centered at half of the target horizon, clipped to available duration. Display unscaled, unsmoothed cached RMS, and actual original note intervals. Selection uses whole-track effects; windows are not selected by local error. If a quadrant is empty, report that rather than substitute another.
3. Next-distinct-onset sensitivity: for every annotation start, set its interval end to the next strictly larger onset within that same track; simultaneous onsets share that end. For the final onset retain each annotation's original end. Quantize with the original int(time/hop) rule, clip to target length, and require at least four frames. No cross-track onset lookup. The primary rule remains original cached offsets. For rule comparisons use the intersection of notes eligible under both rules, so note inclusion is identical. Compute Note, Within and log note-RMSE for all eight models. Compare Mamba against instrument OLS and shared envelope, for all186, URMP136, nonURMP50 and nonBach146. Report same-note original/next-onset differences and coverage, not only interval signs. Bach10 true offsets cannot be recovered; this check is not restoration of true note-off or independent validation.
4. Report original eligible note-duration quantiles and per-track active/silent fractions to contextualize smoothing widths; do not use them to select a favorable scale.

Verification: independently recompute original per-track Note and note-log RMSE from intervals and compare to frozen reports. Verify new next-onset means using cumulative sums as an independent calculation. Preserve complete per-track outputs, unfavorable outcomes and provenance. Main text will use only a compact statement/table; complete plots and definitions belong in an actual supplied companion PDF and data package.
