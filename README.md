# MIDI-to-RMS research

## Current paper: controlled evaluation

**Disentangling Note Levels and Envelope Shape: A Controlled Evaluation of MIDI-to-RMS Prediction**

Start with **[the reproducibility guide](reproducibility/README.md)**. It provides a CPU command to recompute the paper's analyses from included arrays, fixed data roles and SHA256 checks, plus instructions for loading the retained neural checkpoints and checking the additional seeds.

Larger cached inputs and checkpoints are in the **[v0.44.1 reproducibility release](https://github.com/dd3xp/midi/releases/tag/repro-v0.44.1)**. Original recordings are not redistributed. See the guide for what is and is not reproduced. No conference acceptance is implied.

## Earlier work

The other directories preserve earlier experiments and documents. They are historical materials, not the entry point or protocol for the current controlled-evaluation paper. They have not been rewritten as part of this release.
